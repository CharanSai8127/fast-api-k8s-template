# AWS EKS Platform Engineering

Production-oriented Kubernetes platform built on Amazon EKS using GitOps, Argo CD, Kustomize, Observability, Platform Guardrails, and FinOps principles.

This project demonstrates how modern platform teams can design, deploy, and operate scalable, secure, observable, and cost-efficient Kubernetes platforms across multiple environments. The platform enables automated application delivery through GitOps workflows while enforcing operational consistency, governance, environment isolation, and infrastructure optimization.

## Key Capabilities

* GitOps-based deployments using Argo CD
* Multi-environment management using Kustomize overlays
* Automated application delivery across development, staging, and production environments
* Platform guardrails for governance, security, and operational consistency
* Observability through Prometheus, Grafana, and Alertmanager
* Gateway API for application traffic management
* Infrastructure optimization using CAST AI and FinOps practices
* Namespace-based environment isolation
* Automated scaling using Horizontal Pod Autoscaler (HPA)

## Technology Stack

Amazon EKS, Kubernetes, Terraform, Argo CD, Kustomize, Prometheus, Grafana, Alertmanager, Gateway API, CAST AI, GitOps, Platform Engineering
